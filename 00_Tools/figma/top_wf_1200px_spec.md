## 3. Figmaへの自動描画方法

1. **Bridge サーバー起動**
   ```bash
   python3 00_Tools/figma/figma_bridge_server.py
   ```
2. **Figma デスクトップアプリでプラグイン実行**
   * Figmaで指定のファイル (`https://www.figma.com/design/bED5b2sp5NJT5crn1osKMA/Template...`) を開きます。
   * メニュー: `Plugins` > `Development` > `Cline Figma Bridge Plugin` を選択して **Run** します。
3. **自動描画実行**
   ```bash
   python3 00_Tools/figma/draw_top_wf_1200px.py
   ```
