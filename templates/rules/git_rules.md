# Git運用ルール

## ブランチ命名規則
- 新機能・コンテンツ追加: `feature/タスク名-YYYYMMDD`
- 修正・バグ対応: `fix/対応内容-YYYYMMDD`
- リリース用: `release/vX.X.X`

## コミットメッセージ規約
- `feat:` 新しい機能やコンテンツの追加
- `fix:` バグ修正や調整
- `docs:` ドキュメントの修正・更新
- `style:` コードのフォーマット変更（動作に影響なし）
- `refactor:` リファクタリング

## ブランチ・マージの基本フロー
1. 作業開始前に最新の `main` ブランチから作業ブランチを作成。
2. 作業完了後、ローカルテストおよびプレビューの確認を行う。
3. ユーザー承認を得た上で `main` ブランチへマージし、作業ブランチを削除する。
