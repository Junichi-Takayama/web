# 案件要件定義書: 〇〇工務店

## システム構成
- **参照元基盤**: `開発/test/root` (Astro v4 + Tailwind CSS)
- **ソースコードディレクトリ**: `clients/〇〇工務店/website/`
- **データ管理**: Astro Content Collections (`src/content/`)
  - 施工事例: `src/content/works/`
  - お知らせ: `src/content/news/`
  - イベント: `src/content/events/`
- **アセット管理**: `src/assets/` および `public/`
- **デプロイ環境**: Cloudflare Pages / Vercel

## 開発・ビルドコマンド
```bash
npm install
npm run dev     # ローカル開発サーバー起動
npm run build   # 静的サイトビルド (dist/ 生成)
```
