# Gemini用 GA4アクセス解析レポート スライド作成プロンプト＆データシート テンプレート

以下は、GA4のCSVデータを基にGeminiでレポートスライド構成案を作成させるためのテンプレートです。

---

## 🤖 Gemini入力用プロンプト

```text
あなたはプロのWebアナリストおよび資料作成の専門家です。
以下に提供する「GA4アクセス解析データ（[対象期間]）」のみに基づき、プレゼンテーション用スライドの構成案（スライドごとにタイトル、概要、ビジュアル配置指示、事実データの箇条書き）を作成してください。

【コンテンツ制約事項・ルール】
1. 事実（提供されたデータ・数値・計算可能な前月比/前年比等）のみを整理して提示してください。
2. 感想、主観的な考察、改善提案、推測は一切含めないでください。
3. 数値は正確に記載し、必要に応じて前月比・前年同月比の増減数および増減率を添えてください。
4. GA4プロパティID等のシステム内部管理用の番号はスライド内に記載・出力しないでください。

【デザイン・ビジュアル演出指示】
1. フリー素材写真は一切使用しないでください。
2. コンサルティング品質の高度なデザイン（アイコン、SVGグラフ、数値カード、カラーバッヂなど）を活用した、スタイリッシュな静的デザインで構成してください。
3. 情報を視覚的に整理するため、重要なKPIは「数値カード」、状態や変化率は「カラーバッヂ」、チャネル比率や推移は「SVGグラフ」や視覚的なレイアウトで表現するよう指定・出力してください。
```

## 🛠 スライド制作へのコンポーネント適用

上記データシートを基にMarpスライドを作成する際は、以下に整備された共通CSSおよびUIコンポーネントを活用してください：
- **コンポーネントカタログ**: `00_Director_References/templates/marp_ga4_components.md`
- **共通CSSテーマ**: `00_Director_References/templates/marp-ga4-theme.css`
- **出力コマンド**:
  ```bash
  # HTML出力
  npx -y @marp-team/marp-cli [スライド].md --html --allow-local-files -o [出力].html
  # PDF出力
  npx -y @marp-team/marp-cli [スライド].md --html --pdf --allow-local-files -o [出力].pdf
  ```
