# microCMS API スキーマ設定仕様書

本書は、ArCraft（地方工務店・中小企業向け超高速Web基盤）における microCMS のエンドポイントおよびフィールド定義仕様書です。
microCMS 管理画面にて以下の2つのエンドポイントを作成・設定してください。

---

## 1. エンドポイント: `news` (お知らせ・新着情報)

* **API名**: お知らせ
* **エンドポイント**: `news`
* **APIの型**: リスト形式

### フィールド定義

| フィールドID | 表示名 | 種類 | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :--- |
| `title` | タイトル | テキストフィールド | ○ | お知らせの表題 |
| `category` | カテゴリ | セレクトフィールド | ○ | 選択肢: `お知らせ`, `サービス`, `機能追加`, `レポート`, `見学会` |
| `content` | 本文 | リッチエディタ | ○ | 本文テキスト、装飾、画像挿入可能 |
| `thumbnail` | サムネイル画像 | 画像フィールド | - | 記事一覧・詳細上部に表示する画像 |

---

## 2. エンドポイント: `works` (制作・施工事例)

* **API名**: 制作・施工事例
* **エンドポイント**: `works`
* **APIの型**: リスト形式

### フィールド定義

| フィールドID | 表示名 | 種類 | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :--- |
| `title` | タイトル | テキストフィールド | ○ | 例: `中庭を囲む光のコートハウス` |
| `subTitle` | 英語サブタイトル | テキストフィールド | - | 例: `Courtyard House in Setagaya` |
| `tag` | 事例タグ | テキストフィールド | ○ | 例: `建築・施工事例`, `Web制作事例` |
| `location` | 所在地・エリア | テキストフィールド | ○ | 例: `東京都世田谷区`, `神奈川県鎌倉市` |
| `type` | 構造・規模・種別 | テキストフィールド | ○ | 例: `新築注文住宅 / 木造2階` |
| `mainImage` | メイン画像 | 画像フィールド (またはURL) | ○ | 一覧カードおよび詳細アイキャッチ |
| `slides` | スライダーギャラリー | 繰り返しフィールド (または複数画像) | - | スライド写真群（下記サブフィールド定義参照） |
| `specs` | 物件概要・仕様テーブル | 繰り返しフィールド | - | ラベルと値のペア（下記サブフィールド定義参照） |
| `conceptTitle` | コンセプト見出し | テキストフィールド | - | 例: `都市の喧騒を忘れ、空と光を取り込む静謐の住まい` |
| `conceptBody` | コンセプト本文 | テキストエリア / リッチエディタ | - | 空間設計やWeb制作の狙い・詳細 |
| `comment` | 担当者コメント | テキストエリア | - | 設計士・ディレクターからのメッセージ |
| `designer` | 設計・制作担当者 | テキストフィールド | - | 例: `一級建築士 高山 潤一` |

#### `slides`（スライダーギャラリー繰り返し項目）のサブフィールド
1. `title`: テキストフィールド（写真見出し）
2. `image`: 画像フィールド（スライド画像URL）
3. `caption`: テキストフィールド（写真の詳しい解説文）

#### `specs`（物件概要・仕様テーブル繰り返し項目）のサブフィールド
1. `label`: テキストフィールド（項目名、例: `所在地`, `構造・規模`, `耐震性能`）
2. `value`: テキストフィールド（内容、例: `耐震等級3`, `HEAT20 G2`）

## 3. 環境変数（`.env`）の設定

microCMS でサービスを作成後、発行された情報をローカルの `templates/astro_v2/.env` に設定してください。

```bash
# templates/astro_v2/.env
MICROCMS_SERVICE_DOMAIN=xxxxxx  # https://xxxxxx.microcms.io の xxxxxx 部分
MICROCMS_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

※環境変数が未設定の場合、あるいは通信エラー発生時は、自動的に内蔵モックデータがフォールバック表示されるため、ローカル開発およびビルドは常に安全に動作します。
